# AoC Dashboard v2 — Plan (approved 2026-10-29)

Full rework of the dashboard using **React 19 + TypeScript + Vite + Tailwind v4** and the
[ascii/cnlibs](https://ascii.cnlibs.com/docs) component library (shadcn-style registry,
ASCII-drawn frames on a `ch`/`lh` character grid, Base UI primitives).

## Decisions

- **In-place rebuild of `dashboard/`** (old version lives in git history; deploy scripts preserved).
- **TypeScript**, minimal Tailwind utility usage — library's own styling first.
- AoC 2025 has **12 days** → 12-tile calendar, total stars `N / 24`.
- Detail view = **persistent side panel** (calendar shrinks left, details right); narrow screens → `Sheet side="right"`.
- **Star indicator = plain `*`**: gold filled `*`, dimmed `*` for missing, with `N/2` tooltip / aria-label.
- **Manual stars config** `src/data/stars.json` (day → `stars: 0|1|2`); scripts never rewrite it.
- Font: **Fira Code** (Google Fonts css2 link), wired via `--font-ascii` var.
- Theme: ASCII dark palette `phosphor` overridden with canonical AoC colors.
- Keep `react-syntax-highlighter` for code view (dimming via `highlight_ranges` + copy button).
- Future: `benchmarks.json` (day/part/language/ms) consumed by the Stats tab — placeholder now.

Constrained: no changes to `go/`, `python/`, `cpp/` solutions or `inputs/`.

## Data

- `src/data/progress.json` — generated by `scripts/update_progress.py` (languages auto-scanned
  from `go|python|cpp/dayNN/solution.*`; title + article HTML from
  adventofcode.com via `scripts/scraper.py`; per-lang `content`, `highlight_ranges`, `completed`).
- `src/data/stars.json` — manual: `{ "1": { "stars": 2 }, … }` for days 1–12
  (seeded `day1→2, day2→2` from current statuses; user-tunable).
- `src/lib/types.ts` — DayData/LangData types; `src/lib/data.ts` — merge progress ⨉ stars,
  totals for header (`N of 24 stars`, language counts).

## UI structure (src/)

- `App.tsx` — layout + selection state + keyboard (Esc clear, ↑/↓ move day).
- `DashboardHeader.tsx` — AsciiBox banner, Progress `N / 24 stars`, language counts.
- `CalendarPanel.tsx` / `DayTile.tsx` / `Stars.tsx` — framed tiles, bar-era styling:
  day number, title, stars, language Badges (strong when per-lang `completed`), dim no-data state.
- `DetailPanel.tsx` — Empty state when nothing selected; otherwise framed panel with
  **Tabs: Task / Solutions / Stats**.
- `TaskView.tsx` — AoC article HTML in ScrollArea (links/code/star accents restyled), link to AoC.
- `SolutionView.tsx` + `CodeViewer.tsx` — language ToggleGroup + viewer with highlight ranges.
- `StatsView.tsx` — placeholder table (Day/Part/Language/Time), ready for future benchmarks.json.
- Responsive: `lg:` Resizable/flex split; below that Sheet overlay.

## Setup commands

```bash
pnpm dlx shadcn@latest add https://ascii.cnlibs.com/r/{component}.json       # once per component
# badge tabs scroll-area tooltip progress empty skeleton spinner toggle-group
# toggle card resizable sheet marker
```
